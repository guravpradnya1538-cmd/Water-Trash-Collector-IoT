# Water Trash Collector Using IoT

This project is designed to remove floating waste from water bodies such as rivers, lakes, and ponds.  
It uses a motor-driven mechanical setup to collect trash and optionally includes IoT monitoring for status updates.

---

## 🌟 Features
- Automatic trash collection mechanism
- Motor-driven conveyor or paddle wheel
- IoT-based monitoring (optional)
- Eco-friendly and low-cost solution
- Can be scaled for larger applications

---

## 🧩 Components Used
- Arduino / NodeMCU  
- DC Motor  
- L298N Motor Driver  
- Ultrasonic/IR sensor (optional)  
- Battery or power supply  
- Mechanical trash collection setup  

---

## 🛠️ How It Works
1. The motor rotates a collection mechanism (paddle, conveyor, or scoop).  
2. Floating trash is pulled toward the collection area.  
3. IoT module (optional) sends status or motor data to a dashboard.  
4. Simple automation ensures continuous operation.
